ColorForge 2.2.1 makes the player's WAV export safer to upload (Suno and other sites).

**Downloads**

- `ColorForge-VST3-win64.zip`: the plugin. Unzip it, copy the `ColorForge.vst3` folder to `C:\Program Files\Common Files\VST3\`, then rescan plugins in your DAW.
- `ColorForge-Player-win64.exe`: the standalone player, with no install needed. It is unsigned, so Windows SmartScreen may ask for confirmation (*More info → Run anyway*).

**Fixed in 2.2.1**

- **No more half-written exports.** The export is written to `<name>.wav.part` and only gets its real name once it's complete, so you can't pick up an unfinished file and get "unsupported file format".
- **You can see the export running.** It runs in the background with a progress bar and percentage under the status line, and the Export button turns into **Cancel** while it works. A cancelled export leaves nothing behind. When it's done the status says *ready to upload*.
- **Plain PCM WAV files.** Exports now use the simplest standard WAV layout (a 44-byte header, PCM, stereo) instead of the extended format with a padding chunk, which some upload sites reject.
- **Choose 16 or 24-bit.** Clicking Export WAV asks for *16-bit* (for uploads, streaming and CD, with dither) or *24-bit* (studio master). Files at unusual sample rates are converted to 44.1 or 48 kHz.

The plugin itself is unchanged from 2.2.0.
