ColorForge 2.2 adds a transient shaper.

**Downloads**

- `ColorForge-VST3-win64.zip`: the plugin. Unzip it, copy the `ColorForge.vst3` folder to `C:\Program Files\Common Files\VST3\`, then rescan plugins in your DAW.
- `ColorForge-Player-win64.exe`: the standalone player, with no install needed. It is unsigned, so Windows SmartScreen may ask for confirmation (*More info → Run anyway*).

**What's new in 2.2**

- **Transient shaper** on the DYNAMICS page:
  - **ATTACK** (−100 to +100 %) makes hits punchier or softer.
  - **SUSTAIN** lengthens or shortens what rings after each hit.
  - **MIX** and **OUTPUT** set the parallel blend and level.
  - It works from the shape of the level, not a threshold, so it acts the same on quiet and loud material and leaves steady tones alone.
  - A strip shows the boost and cut it is applying.
- **TRANS block in the signal path.** Drag it anywhere in the chain, like the other blocks. Older sessions and presets get it first, ahead of the EQ, switched off.
- **New modulation targets.** ATTACK and SUSTAIN can be modulated by the LFOs, envelope and macros.
- **DRUM PUNCH preset** now uses the transient shaper.

**Status**
