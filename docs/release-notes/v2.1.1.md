ColorForge 2.1.1 fixes the standalone player window on smaller screens.

**Downloads**

- `ColorForge-VST3-win64.zip`: the plugin. Unzip it, copy the `ColorForge.vst3` folder to `C:\Program Files\Common Files\VST3\`, then rescan plugins in your DAW.
- `ColorForge-Player-win64.exe`: the standalone player, with no install needed. It is unsigned, so Windows SmartScreen may ask for confirmation (*More info → Run anyway*).

**Fixed in 2.1.1**

- **The player window fits your screen.** It used to keep the size it had on an external monitor and run off the edges of a laptop screen. Now it shrinks to fit the screen it's on when it opens, when you drag it to another monitor, and when a monitor is unplugged or its scaling changes.
- **The player window is resizable.** Drag its border or maximise it; the whole UI scales together and keeps its shape. Your chosen size comes back when there's room for it.

The plugin itself is unchanged from 2.1.0.
