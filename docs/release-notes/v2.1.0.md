ColorForge 2.1 adds automation lanes to the standalone player and makes the interface 8-bit in look only.

**Downloads**

- `ColorForge-VST3-win64.zip`: the plugin. Unzip it, copy the `ColorForge.vst3` folder to `C:\Program Files\Common Files\VST3\`, then rescan plugins in your DAW.
- `ColorForge-Player-win64.exe`: the standalone player, with no install needed. It is unsigned, so Windows SmartScreen may ask for confirmation (*More info → Run anyway*).

**What's new in 2.1**

- **Automation lanes in the player.**
  - Arm **REC**, press play and move any control. Whatever you hold is written to its own lane, across as many loops as you like.
  - **READ** plays the lanes back.
  - Pick a lane under the waveform to see it. Drag on it to draw, and double-click to clear it.
  - **Lanes...** saves the lanes next to the audio file as `<name>.cfauto`, and they load again with the file.
- **Export WAV** and `--render input.wav output.wav [lanes.cfauto]` render the lanes too.
- **Loudness target readout.** The STATUS column shows how far the short-term and integrated loudness sit from your target, in LU, and whether the true peak went over the limiter ceiling. It replaces the loudness quest: no more lives, timers or "stage clear".

**Status**

52 offline DSP checks and the Windows build run on every change. The plugin has still not been tested inside a DAW, so please report anything odd.
