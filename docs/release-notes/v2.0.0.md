ColorForge 2 turns the color-bass effect into a full mixing and mastering suite for Windows x64, with an original 8-bit game-style interface. Every control is a host parameter, so all of it can be automated in your DAW.

**Downloads**

- `ColorForge-VST3-win64.zip`: the plugin. Unzip it, copy the `ColorForge.vst3` folder to `C:\Program Files\Common Files\VST3\`, then rescan plugins in your DAW.
- `ColorForge-Player-win64.exe`: the standalone player. Run it and drop an audio file on the window to loop it through the suite. **Export WAV** renders the result. No install is needed. The exe is unsigned, so Windows SmartScreen may ask for confirmation (*More info → Run anyway*).

**What's new in 2.0**

- **EQ page.** 8-band parametric EQ (cuts up to 48 dB/oct, shelves, four bells) drawn over a live spectrum.
  - Drag the dots to set bands.
  - Each band can be stereo, mid or side.
  - Bells and shelves can be dynamic.
- **Dynamics page.**
  - Bus compressor with auto makeup, parallel mix, sidechain high-pass and a gain-reduction history.
  - Tape, tube and clip saturator.
  - A signal-path map where you drag modules to reorder the chain.
- **Master page.**
  - Lookahead true-peak limiter.
  - Stereo width with mono bass.
  - Input and output gain.
  - A 60-second loudness map.
- **Mod page.**
  - Two LFOs, free running or synced to the DAW tempo and bar.
  - An envelope follower and four macro knobs.
  - An 8-slot matrix that routes them to 38 targets.
- **Status column.**
  - LUFS momentary, short-term and integrated, true peak, phase and gain reduction.
  - A level-matched bypass for fair before/after checks.
  - The Loudness Quest: hold your target LUFS for 30 seconds without clipping to clear the stage.
- **Presets and A/B.** 9 factory presets (mix bus, streaming and club masters, vocal, drums, tape, wide + mono bass, the classic color-bass sound), your own presets on disk, and A/B snapshots.
- **Color FX page.** The original ColorForge chain is still here (pitch map, resonator, shifter, chorus, reverb, OTT, now with movable crossovers and band solo). It is off by default, so it adds no latency unless you use it.
- **Compatibility.** Sessions saved with 1.0 still load.

**Status**

Offline DSP checks (47) and the Windows build run on every change. The plugin has still not been tested inside a DAW, so please report anything odd.
